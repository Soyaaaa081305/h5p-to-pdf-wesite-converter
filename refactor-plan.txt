1. ISSUE DIAGNOSIS & ROOT CAUSE ANALYSIS
--------------------------------------------------------------------------------
1.1 Page & Header Shift on Navigation (/ -> /terms, /privacy):
    - Symptom: When navigating from the Home page to Terms or Privacy, the header,
      logo, buttons, and content visibly shift to the left; navigating back shifts
      them to the right.
    - Root Cause: Classic browser scrollbar layout shift. On Home, content fits
      inside 100vh, so Windows browsers render no scrollbar (client width = full
      viewport). On Terms/Privacy, content exceeds 100vh, causing Windows Chromium
      to render a 15-17px vertical scrollbar on the right. Because `.max-w-7xl.mx-auto`
      centers within the client width, the midpoint shifts left by ~8.5px.
    - Solution:
      * Add `scrollbar-gutter: stable;` and `overflow-y: scroll;` to `html` in `src/index.css`.
      * Add sleek, modern custom scrollbar styling with a transparent track so the
        permanent track is visually seamless in both light and dark mode.
      * Result: The client width is identical on all pages, completely eliminating
        any layout shift or jumping.

1.2 Redundancy & Flow Audit:
    - Verify that no dead files, duplicate utility functions, or unused variables exist.
    - Standardize branding: Ensure `<LogoMark />` from `src/components/Logo.tsx` is
      the single source of truth for the app logo across Header, Study Reviewer,
      and Study Reviewer Dock.
    - Verify data flow between `App.tsx`, `StudyReviewerDock.tsx`, and `StudyReviewer.tsx`:
      Ensure the 3-stage width lifecycle, source selection (Course text/PDF + videos),
      custom prompt overrides, and direct PDF download flow seamlessly.
    - Verify clipboard copying: Ensure rich HTML and clean Markdown copy works smoothly
      with reliable fallbacks for all browsers.
    - Verify question limits in `src/lib/gemini.ts`: Ensure user question choices (5, 10,
      15, 20, 25) and custom prompt overrides are preserved without arbitrary truncations.
